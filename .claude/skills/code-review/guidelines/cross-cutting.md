# cross-cutting

## Clean Architecture

- CLAUDE.mdのlayer分担（domain/infra/interactor/interface）から逸脱していないか
- 値型かポインタ型か: 「結果なし」を表現する必要が無いなら値型を使う（nilは本来「結果が無いこと」を表現するためのもの）

## 変更の粒度

- タスクに不要な既存コードのリファクタ・拡張が混ざっていないか（過剰実装）

## コメント・ドキュメント

- WHYが非自明な場合のみコメントを許容する。WHATを説明するだけのコメントは指摘する
- ハードコードされた具体的な値（AWSアカウントID、ARN等）が紛れ込んでいないか
